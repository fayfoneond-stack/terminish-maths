=============================== COMMENT COMPILER SUR OVERLEAF ==============================

1) Menu "New Project"  ->  "Upload Project"  ->  choisir ce fichier ZIP.
2) Overleaf ouvre main.tex : cliquez sur "Recompile".
   - Le compilateur est impose par le fichier :  % !TEX program = pdflatex
   - Les 14 figures sont ECRITES DANS le fichier : aucun dossier d'images a
     televerser, donc plus d'erreur "File `figures/...' not found".

SI VOUS GARDEZ VOTRE PROJET ACTUEL (recommande si vous avez deja tout tape) :
   a) dans Overleaf, supprimez l'ancien main.tex : a droite de son nom, "..." ->
      Delete (le projet doit etre vide de tout ancien main.tex) ;
   b) icone Upload (la fleche, en haut a gauche) -> "Select from your computer" ->
      choisissez le NOUVEAU main.tex  ->  "Upload" ;
   c) Recompile.  Si Overleaf demande quel fichier compiler, menu "Menu" ->
      "Main document" -> main.tex.
   ATTENTION : si l'erreur "File `figures/fig_equilibre.tex' not found" revient,
   c'est que l'ANCIEN main.tex est encore dans le projet (le nouveau, lui, ne
   contient aucun appel \input ni aucun nom de figure externe).

AUTRE METHODE (copier-coller) : ouvrez main.tex dans le ZIP, Ctrl+A puis Ctrl+C,
puis dans Overleaf ouvrez main.tex, Ctrl+A, Supprimer, Ctrl+V, Recompile.

======================================== CONTENU ============================================

   Page 1     en-tete administratif ; grand encadre vert (competence terminale, theme,
              lecon, nombre de seances, supports, materiel, consigne, prerequis) ;
              tableau Capacites / Contenus ; strategie pedagogique.
   Seance 1   Notion de barycentre : deux points ponderes, puis plus de deux points.
   Seance 2   Proprietes du barycentre : alignement, droites concourantes, paralleles.
   Seance 3   Notion de ligne de niveau : definition, MA^2+MB^2 = k, MA^2-MB^2 = k.
   Seance 4   Lignes de niveau de MA.MB = k, de MA/MB = k (cercles d'Apollonius) et de
              ||a.MA + b.MB|| = k ; mathematisation d'un probleme ; bilan.

   EFFECTIF et SEMAINE sont laisses en pointilles, comme sur votre fiche modele.
