>>> SI VOUS AVEZ L'ERREUR :  File `figures/fig_equilibre.tex' not found  <<<
C'est que le fichier a ete televerse SEUL, sans le dossier "figures/".
Deux solutions, au choix :

SOLUTION 1 (la plus simple, rien a televerser)
   Le fichier main.tex de cette archive est AUTONOME : les 14 figures
   sont ecrites a l'interieur du fichier (TikZ).
   - Option a : menu "New Project" -> "Upload Project" -> choisir cette archive ZIP.
     Overleaf ouvre main.tex et vous cliquez sur "Recompile".
   - Option b (pour garder votre projet actuel) : ouvrez main.tex sur Overleaf,
     selectionnez tout (Ctrl+A), supprimez, collez tout le contenu du fichier
     main.tex fourni ici, puis "Recompile".

SOLUTION 2 (garder le projet decoupe)
   Televersez AUSSI le dossier "figures" (les 14 fichiers fig_*.tex) en plus du
   fichier "fiche_barycentres_lignes_niveau.tex" : le dossier doit s'appeler
   exactement "figures" et se trouver a cote du .tex.

A SAVOIR
   - Compilateur a utiliser : pdfLaTeX (menu "Menu" -> "Compiler").
     Les deux fichiers contiennent la ligne  % !TEX program = pdflatex
     qui l'impose automatiquement.
   - Les figures sont dessinees par TikZ pendant la compilation : aucun
     fichier image n'est necessaire.
   - EFFECTIF et SEMAINE ont ete laisses en pointilles, comme sur la fiche modele.
