Fiche « Barycentres et lignes de niveau » — 1re D

Canevas de la fiche Leçon 2 · A4 paysage · filigrane · 4 séances · exercices d'application avec solutions rédigées · compilation pdfLaTeX

1. Téléchargez le fichier

⬇︎ Télécharger main.tex Le fichier complet et autonome : les 14 figures sont à l'intérieur, rien d'autre à téléverser. ⬇︎ Télécharger l'archive ZIP (main.tex + figures + mode d'emploi) Pratique pour « New Project → Upload Project » sur Overleaf. ⬇︎ Voir l'aperçu de la mise en page (image)

2. Mettez-le dans Overleaf — deux méthodes

  1. Remplacer le fichier de votre projet actuel (le plus simple) :
    Dans Overleaf, cliquez sur l'icône Upload (flèche vers le haut, en haut à gauche du panneau des fichiers) → choisissez le main.tex téléchargé → Overleaf demande de remplacer le fichier existant : acceptez → cliquez sur Recompile.
  2. Ou créer un projet neuf : menu New Project → Upload Project → déposez l'archive Fiche_Barycentres_Lignes_Niveau.zip → Overleaf ouvre main.tex → Recompile.
Pourquoi ça refusait : l'erreur File 'figures/fig_equilibre.tex' not found signifie que le projet compile encore l'ancien fichier, qui appelle des figures rangées dans un dossier figures/ absent. Le nouveau main.tex n'appelle plus aucun fichier : les 14 figures sont écrites dans le document lui-même. Après remplacement, l'erreur disparaît.
Bon à savoir : la ligne % !TEX program = pdflatex en tête du fichier impose le bon compilateur. Les figures sont dessinées par TikZ pendant la compilation : aucun fichier image n'est nécessaire. EFFECTIF et SEMAINE sont laissés en pointillés, comme sur votre fiche modèle.

3. Si un message rouge apparaît encore

  1. Cliquez sur Logs à côté de Recompile.
  2. Copiez les 2 ou 3 lignes en rouge (celles qui commencent par !).
  3. Envoyez-les moi : je corrige aussitôt.
